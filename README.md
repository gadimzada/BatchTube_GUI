# BatchTube V2 - Advanced GUI for yt-dlp

## 🚀 About the Project
**BatchTube V2** is an open-source Graphical User Interface (GUI) with multi-language support, designed to make `yt-dlp`—the popular and powerful command-line video downloader—easy for everyone to use. It allows you to download videos or just audio (MP3) in the highest quality without dealing with terminal screens or complex command strings. It was developed from scratch using Python (Tkinter).

## ✨ Key Features
*   **Fully Offline & No Installation Required:** Runs as a single `.exe` file (Portable). Just download and start using it; no installation is needed.
*   **Multi-Language Support (9 Languages!):** Supports Turkish, English, Azerbaijani, Russian, Portuguese, French, Spanish, Chinese, and Japanese.
*   **Dynamic Theme Engine:** Instantly switch between an eye-friendly Dark theme and a Classic Light theme. Interface elements adapt perfectly to the selected theme.
*   **High-Quality Video Downloading (MP4):** Saves videos from YouTube and other supported platforms in MP4 format by automatically combining the best available video and audio quality (`bestvideo+bestaudio`).
*   **Audio Downloading with Metadata (MP3):** Downloads videos as high-quality MP3 audio files. Video thumbnails and metadata are automatically embedded into the downloaded MP3 files. *   **Smart Cookie Support:** Transfers session cookies from your Chrome, Edge, Firefox, Brave, or Opera browsers to `yt-dlp` with a single click, enabling the download of age-restricted, members-only, or login-required videos. (A "Cookie-free" mode can also be selected if desired).
*   **One-Click Update:** You can trigger `yt-dlp`'s built-in update mechanism (`-U`) directly from the interface with a single click, ensuring your setup remains up-to-date.
*   **Live Process Log:** Download speed, estimated time, file size, and any errors are displayed in real-time on the in-app console (log) screen.
*   **Adjustable Interface:** Thanks to the freely resizable window layout, you can easily view long links or detailed logs.

## 🛠️ How to Use?
1.  **Requirements:** For the program to function, an up-to-date `yt-dlp.exe` file must be present in the same folder. (It is also highly recommended to have `ffmpeg.exe` in the folder for high-resolution video/audio merging operations).
2.  Run `BatchTube.exe`.
3.  Select the "Save Folder" where downloaded files will be stored.
4.  Select a browser (for cookies) if applicable, or leave it as "Cookie-free."
5.  Paste the link of the video you wish to download.
6.  Click the "Download Video (MP4)" or "Download Audio (MP3)" button.
